## 📌 About

This portfolio represents my journey as a **B.Tech Computer Engineering student** and **Full Stack Developer**. It highlights my technical skills, projects, internship experience, certifications, and ways to connect with me.

The website focuses on providing a smooth user experience with modern animations, responsive design, and clean UI.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/yourusername/portfolio.git
```

### 2. Navigate to the project

```bash
cd portfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start development server

```bash
npm run dev
```

The application will be available at

```
http://localhost:3000
```

---

## 📦 Build for Production

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
